# Full-Stack E-Commerce Application

A full-stack e-commerce web application currently in active development.  
The project demonstrates core e-commerce functionality including user authentication, product management, and shopping cart features.

**Status:** In progress – core features implemented, further development ongoing.

##Live Demo
- Visit the deployed application: https://nx-gift-store.vercel.app/

## Features

### Currently Working
- User registration and login (authentication)
- Product catalogue with listing and basic details
- Shopping cart (add / remove items)
- Responsive layout for desktop
- Payment integration

### In Progress / Planned
- Order processing and history
- Admin dashboard
- Product search and filtering
- Responsive layout for both desktop and mobile
- Product admin view

## Tech Stack

**Frontend:**  
React, Vite

**Backend:**  
NodeJS + Express

**Database:**  
PostgreSQL

**Other tools:**  
- Version Control: Git, GitHub
- Styling: Tailwind CSS
- Authentication: JSON Web Tokens (JWT)
- Database: Supabase (PostgreSQL)
- Deployment: Vercel (frontend), Render (backend)
- Payments: Stripe Checkout

## Getting Started

### Prerequisites
- Web browser
- Internet connection
