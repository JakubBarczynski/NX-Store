# Full-Stack E-Commerce Application

A full-stack e-commerce web application currently in active development.  
The project demonstrates core e-commerce functionality including user authentication, product management, and shopping cart features.

**Status:** In progress – core features implemented, further development ongoing.

## Features

### Currently Working
- User registration and login (authentication)
- Product catalogue with listing and basic details
- Shopping cart (add / remove items)
- Responsive layout for desktop and mobile

### In Progress / Planned
- Payment integration
- Order processing and history
- Admin dashboard
- Product search and filtering
- Deployment
- Responsive layout for both desktop and mobile
- Product admin view

## Tech Stack

**Frontend:**  
React, Vite

**Backend:**  
NodeJS + Express

**Database:**  
PostgreSQL

**Other tools:**  
- JWT
- TailwindCSS
- Git & GitHub
